# Roadmap

## Phase 1 — Echo vertical slice (current)

Prove Murmur's identity, three-pulse observation, local decision tension, mobile layout, typed bootstrap, and real Reddit embedding.

## Phase 2 — Daily expedition foundation (next)

Design the authoritative day-state machine, installation-scoped Redis schema, idempotent scheduler transitions, vote submission contract, and deterministic resolution tests. Preserve the current Echo presentation while replacing local selection with explicit server state.

## Later phases (not authorized yet)

1. Real per-user sensor assignment and privacy threat model
2. Thread/community integration and moderation-safe discussion affordances
3. Heat and Wind mechanics with distinct informational value
4. Multi-day expedition content and human playtesting
5. Reliability, observability, abuse cases, accessibility audit, and App Review preparation

No economy, combat, clans, inventory, or generative content is planned for the core product.
