# Fallback navigation and sensor guidance results

Date: 2026-07-15. Generated by `npm run evidence:guidance` against real Chrome headless over CDP.

## Summary

- **11 navigation cases and 18 guidance cases, 0 failures**, across 360×800, 390×844, 412×915,
  768×1024, 1280×720 and 360×800 with reduced motion.

## OPEN COMMENTS

The control was an `<a target="_blank">`, which Reddit's sandboxed webview blocks — the click did
nothing. It now calls Devvit's installed client capability, `navigateTo(url)`.

Working destination (360×800):

```json
{ "lastUrl": "https://www.reddit.com/comments/local_chapter", "outcome": "requested",
  "navigationInvokedOnce": true, "targetSize": [167, 44], "claimedPublication": false }
```

- The URL is the canonical comments URL of the post being read, `t3_` stripped, absolute and
  parseable by `new URL()` (which is what `navigateTo` requires).
- Exactly one navigation request per explicit click; a re-click is a deliberate second request, and a
  double tap while navigating is ignored.
- The fallback never claims publication in any case.

Broken destination (fixture-forced, 360×800):

```json
{ "outcome": "failed", "errorStateShown": true, "copyStatus": "Comments link copied.",
  "claimedPublication": false }
```

`COULDN'T OPEN COMMENTS` appears with `COPY COMMENTS LINK` and `TRY AGAIN`; the error clears on
retry and never persists when navigation works. Copying and navigating remain separate actions.

## Sensor guidance

The instruction was removed by a fixed 1.8 s timer regardless of interaction, so a player who had
not yet touched the cavern lost the only explanation of the gesture. Guidance is now driven purely
by interaction — there is no timer at all.

- Intro still present **~5.6 s after load with zero interactions on all 6 viewports**.
  Before: `"Press and hold to focus the heat."`
- After the first activation it compacts without disappearing:
  `"A localized warm gradient gathers near the south.\nHold to focus · 1 of 3"`
- `HOW TO SENSE` restored the help on all 6 viewports and closes back to the compact line.
- Because no timing is involved, reduced motion has exactly the same reading time.

## Boundary

`navigateTo` is fire-and-forget: it throws only on an invalid URL and cannot report whether the host
honoured the effect. This evidence proves the handler invokes Devvit navigation with the correct
destination; **whether Reddit opens the comments is the human test and is not recorded as passing.**
