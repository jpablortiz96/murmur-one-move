# Consequence system

The winning direction is applied to the hidden server scenario after vote resolution. Community choice always wins the vote protocol; the consequence engine does not secretly replace it with the optimal route.

## Severity

- `safe`: no vitality loss, one memory fragment.
- `costly`: no vitality loss, one durable scar.
- `dangerous`: one vitality loss and one durable scar.

Structural decoys and ambiguous passages are costly; immediate collapses are dangerous. Scars are unique, retained across posts and rendered as shape/line changes on Murmur rather than color alone. Vitality changes the core and silhouette; memory adds orbiting fragments.

The consequence record stores stable tags and public copy, not only prose. This allows replay, simulation and future visual upgrades without rewriting historical meaning.

## Endings

- Chorus: memory >= 3 and vitality >= 2.
- Fading: vitality = 0.
- Survivor: every other valid Day 7 state.

The calibrated 10,000-run evidence produced all three endings and no invalid terminal states. Distribution is evidence, not a promise of equal probability.
