# Roadmap

## Phase 1 — Echo vertical slice (complete)

Prove Murmur's identity, three-pulse observation, local decision tension, mobile layout, typed bootstrap, and real Reddit embedding.

## Phase 2 — Transactional community round (complete)

Persist one active vote per authenticated player, allow atomic changes, expose aggregates, freeze an auditable immutable result through a moderator action, and play the consequence in Phaser. Scheduler automation remains excluded.

## Phase 3 — Server-authoritative perception (next)

Implement real per-user Echo/Heat/Wind assignment and server-side World Truth with leak-tested partial projections. The repository received for the transactional phase did not contain those assumed systems, so they must be built and audited before automatic cadence.

## Later phases (not authorized yet)

1. Thread/community integration and moderation-safe discussion affordances
2. Heat and Wind mechanics with distinct informational value
4. Multi-day expedition content and human playtesting
5. Reliability, observability, abuse cases, accessibility audit, and App Review preparation

No economy, combat, clans, inventory, or generative content is planned for the core product.
