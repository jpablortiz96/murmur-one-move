# Input and mobile resolution results

Date: 2026-07-15. Generated by `npm run evidence:resolution` against real Chrome headless over CDP.

## Summary

- **42 cases, 0 failures** across 360×800, 390×844, 412×915, 768×1024, 1280×720 and 360×800 with
  reduced motion.
- Every stage case is **exclusive**: exactly one layer owns the main zone.
- Every stage case has **no internal scroll** (document size equals the viewport).
- Stage advance was driven by **real mouse events**, so each primary control is proven hittable.
- The moderator tray is **closed by default on all six configurations** and opens only on demand.
- **REPLAY OUTCOME restarts the sequence at `summary` on all six configurations.**

## Exclusivity (the defect)

Previously Three Truths (depth 80, opaque ellipse), the map line (depth 55), the result text and the
moderator buttons (depth 60) were all rendered at once, so the reveal covered the controls on
mobile. Now, for example at 360×800 in `three-truths`:

```json
{ "activeLayers": ["threeTruths"],
  "buttons": { "stageCta": { "visible": true }, "replay": { "visible": false },
               "modResolve": { "visible": false }, "modAux": { "visible": false } } }
```

Stages reached and verified: `summary`, `three-truths`, `consequence`, `expedition-map`,
`next-action`.

## Sequence

`summary → three-truths → consequence → expedition-map → next-action`, each with a single primary
action (`REVEAL THE THREE TRUTHS`, `SEE THE CONSEQUENCE`, `VIEW THE EXPEDITION`, `CONTINUE`). The
summary auto-advances after a short beat (1.7s, shortened to 0.7s under reduced motion) but can
always be advanced manually. Reduced motion shortens beats and drops tweens; it never removes a
stage, so no information is skipped — the reduced-motion column reaches every stage.

## Moderator tray

Moderator controls no longer sit on the player's result. In the terminal stage a discreet
`MOD TOOLS` toggle opens a tray in its own row; `PUBLISH NEXT DAY` / `RECONCILE` exist only while it
is open. A normal player (`canManage: false`) has no tray at all, so it can never render or capture
input.

## Boundary

This is real-browser verification of layout, exclusivity and pointer hit-testing against the local
fixture server. It is not a Reddit playtest: moderator authorization, real Redis and the Field Notes
composer/preview visuals still require the human run recorded in
`evidence/field-notes/raw/reddit-playtest.json`.
